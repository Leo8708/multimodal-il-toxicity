# Processed data

Raw data are available on [figshare](https://doi.org/10.6084/m9.figshare.27979307). See [datasets/README.md](../datasets/README.md) for download and input preparation.

Files generated by the preprocessing and feature extraction scripts:

| File | Contents |
| --- | --- |
| `processed_data.npz` | Fingerprints (`X_num`), targets (`y`), molecular weights (`Mw`), endpoint labels and encodings, image paths, and split indices. |
| `used_dataset.xlsx` | Structures, cell lines, toxicity values, molecular weights, and split labels. |
| `rdkit_descriptors.npz` | Raw and normalized values of 20 molecular descriptors, with their names. |
| `img_features_resnet18.npz` | 512-dimensional image features stored as `features`. |
| `molecular_images/` | Molecular structure images. |

Generate these files from the repository root:

```bash
python prepare_dataset.py
python extract_descriptors.py
python data_utils.py
```

Targets use `y = log10(toxicity_mM * 1000)`. Keep the same row order across the Excel file and feature arrays.
